01 / HOW IT WORKS Completely serverless • Zero code changes required
STEP 01

1-Click Cross-Account Role

Deploy our verified CloudFormation template in your AWS account. Fuse gets scoped, read-only CloudWatch metric access and WAF IP Set edit permissions via short-lived sts:AssumeRole. Zero IAM credentials shared.

STEP 02

Continuous Bedrock Sentinel

EventBridge polls CloudWatch metrics every 60 seconds completely out-of-band. Our deterministic decision engine and Amazon Bedrock evaluate caller diversity, volume deltas, and deployment heartbeats without adding 1ms of proxy latency.

STEP 03

Surgical WAF Isolation

When a runaway loop or single-caller spike is detected, Fuse immediately appends the offending IP to AWS WAFv2. Bad callers get dropped with HTTP 403 at the regional edge; all legitimate users keep flowing with 100% uptime.
