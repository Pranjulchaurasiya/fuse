01 • CIRCUIT ARCHITECTURE FLOW Zero-proxy telemetry convergence • Deterministic classification • Surgical WAF isolation
PHASE 1 Telemetry Ingestion

EventBridge polls CloudWatch metrics every 60s out-of-band. Correlates volume surges with the Deployments DynamoDB heartbeat to separate intentional canary releases from rogue spikes.

PHASE 2 Cognitive Classification

Deterministic statistics compute standard deviation (Z-score ≥ 2.5) and caller concentration. Asynchronous Amazon Bedrock Converse runs structured JSON verification without blocking mitigation.

PHASE 3 Surgical Enforcement

Remediator appends the offending /32 CIDR to the regional WAF IP Set (fuse-blocked-ips). Only rogue callers receive HTTP 403; all legitimate traffic flows uninterrupted. Auto-recovers after 15m.

Zero-Trust Cross-Account Isolation

You never provide IAM long-term access keys or secrets to Fuse. Integration uses AWS standard cross-account roles with a unique, cryptographically random ExternalId. Fuse assumes the role on-demand via sts:AssumeRole for 15 minutes only to inspect CloudWatch metrics and write WAF IP blocks. You can revoke access instantly with one click by deleting the CloudFormation stack.
