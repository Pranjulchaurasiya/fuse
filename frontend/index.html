04 / JUDGING CRITERIA & ARCHITECTURE PROOF First Commit (Bharat Builds Tour) Evaluation Guide
01

The Real Problem

Serverless auto-scaling hides runaway loops. An infinite client retry, unhandled 500 loop, or recursive LLM agent can fire thousands of requests per second, accumulating catastrophic AWS bills before human operators wake up.

02

Single-Turn Bedrock Sentinel

Rather than brittle static thresholds that block legitimate flash sales, Fuse invokes Amazon Bedrock via the Converse API with toolConfig. It correlates caller diversity with deployment heartbeats to classify anomalies with high confidence.

03

Production Safety Gate

While dev/staging environments are throttled automatically, production traffic never auto-throttles blindly. Runaway anomalies are safely withheld in DynamoDB ApprovalQueue until confirmed with a single click.

04

Zero Request-Time Overhead

Fuse never sits as an inline proxy on the client request path. A 1-minute EventBridge poller monitors CloudWatch metrics out-of-band, preserving 100% of native AWS API Gateway and Lambda performance.
